# Naming Conventions

## Files
Use `snake_case.dart`.

```text
app_button.dart
user_profile_screen.dart
booking_repository.dart
```

## Classes
Use PascalCase.

```dart
class AppButton {}
class UserProfileScreen {}
```

## Variables and Methods
Use camelCase.

```dart
final selectedService;
void loadBookings() {}
```

## Constants
Use descriptive semantic names.

```dart
AppSpacing.md
AppRadius.card
AppSizes.buttonHeight
```

## Avoid
Names such as:

```text
common1.dart
widget2.dart
test_screen.dart
new_file.dart
```

Names must describe responsibility.
